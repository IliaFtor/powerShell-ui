Эта инструкция превратит стандартный синий/черный PowerShell в быстрый, красивый терминал с иконками, подсветкой, умным поиском и меню быстрого подключения к SSH-серверам.

---

## Шаг 1. Установка утилит и шрифта

Откройте **PowerShell** (лучше от имени Администратора) и по очереди (или всё сразу) вставьте следующие команды:

```powershell
# Красивая строка приглашения (Starship)
winget install --id Starship.Starship -e

# Умный переход по папкам (замена cd)
winget install --id ajeetdsouza.zoxide -e

# Интерактивный поиск по истории и меню для SSH (fzf)
winget install --id junegunn.fzf -e

# Красивый вывод файлов и папок с иконками (замена ls)
winget install --id eza-community.eza -e

# Просмотр файлов с подсветкой кода (замена cat)
winget install --id sharkdp.bat -e

# Шрифт с иконками (обязательно, иначе вместо иконок будут квадратики!)
winget install --id DEVCOM.JetBrainsMonoNerdFont -e
```

### Модули для самого PowerShell:
Выполните в том же окне (на запрос подтверждения нажимайте `Y` и `Enter`):
```powershell
Install-Module -Name Terminal-Icons -Repository PSGallery -Force
Install-Module -Name PSFzf -Repository PSGallery -Force
```

---

## Шаг 2. Включаем шрифт с иконками

Чтобы терминал не показывал квадратики `[]` вместо значков:

1. Откройте **Windows Terminal** и нажмите **`Ctrl + ,`** (откроются Настройки).
2. В левом меню в самом низу выберите **Профили → По умолчанию (Defaults)**.
3. Перейдите во вкладку **Оформление (Appearance)**.
4. В пункте **Шрифт (Font face)** выберите **`JetBrainsMono Nerd Font`**.
5. Нажмите **Сохранить** в правом нижнем углу.

---

## Шаг 3. Настройка внешнего вида (Starship)

1. Создайте папку для конфига и откройте файл настроек в Блокноте (или VS Code):
   ```powershell
   New-Item -ItemType Directory "$HOME\.config" -Force
   notepad "$HOME\.config\starship.toml"
   ```
   *(Физически файл создастся по пути `C:\Users\<Твоё_Имя>\.config\starship.toml`)*.

2. Вставьте туда содержимое вашего файла **`starship.toml`** и сохраните (`Ctrl + S`).

---

##  Шаг 4. Настройка профиля PowerShell (Алиасы и функции)

1. Откройте файл вашего профиля командой:
   ```powershell
   notepad $PROFILE
   ```
   *(Физически файл лежит примерно тут: `C:\Users\<Твоё_Имя>\OneDrive\Документы\PowerShell\Microsoft.PowerShell_profile.ps1` — если папки еще нет, PowerShell сам предложит её создать, нажмите **Да**).*

2. Скопируйте содержимое вашего готового файла **`Microsoft.PowerShell_profile.ps1`**, вставьте в открывшийся файл и сохраните (`Ctrl + S`).

3. Перезапустите терминал или примените настройки сразу командой:
   ```powershell
   . $PROFILE
   ```

*(Если PowerShell ругнется красным текстом на запрет выполнения скриптов, выполните один раз: `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` и снова введите `. $PROFILE`).*

## Шпаргалка по новым командам

| Команда / Клавиши | Что делает |
| :--- | :--- |
| **`tachki`** | Открывает меню выбора SSH-сервера из `~/.ssh/config` (управление стрелками) |
| **`ls`** | Таблица файлов с правами, владельцем и размером |
| **`ll` / `la`** | Подробный список файлов / скрытые файлы с иконками (`eza`) |
| **`tree`** | Показать структуру папок деревом |
| **`cat <файл>`** | Красиво показать содержимое файла с подсветкой синтаксиса (`bat`) |
| **`z <папка>`** | Мгновенный прыжок в любую папку, где вы уже бывали (`zoxide`) |
| **`..` / `...`** | Перейти на 1 или 2 папки назад |
| **`vsc`** | Запустить VS Code |
| **`hisvsc`** | Открыть файл всей истории введенных команд в VS Code |
| **`powhel`** | Вывести эту справку прямо в терминал |
| **`Ctrl + R`** | Умный поиск по истории команд |
| **`Ctrl + F`** | Быстрый поиск файлов в текущей папке |

---

##  Как добавлять серверы для команды `tachki`

Откройте файл `C:\Users\<Твоё_Имя>\.ssh\config` и записывайте серверы так (комментарий с `#` прямо над `Host` будет отображаться в меню выбора):

```text
# описания
Host названия машины
    HostName 192.168.0.100
    User horo
```
